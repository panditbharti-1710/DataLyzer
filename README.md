# DataLyzer

DataLyzer is a CSV Data Analysis and Visualization Web Application built using Python, Flask, HTML, and CSS. It helps users upload datasets, clean data, analyze information, and generate visual insights through interactive charts.

## Features

- CSV File Upload and Validation
- Data Cleaning and Preprocessing
- Missing Value Handling
- Duplicate Record Removal
- Statistical Data Analysis
- Data Visualization using Charts
- Bar Charts
- Line Charts
- Pie Charts
- Histograms
- Scatter Plots
- Automated Insight Generation
- Data Export Functionality
- User-Friendly Web Interface

## Tech Stack

### Backend
- Python
- Flask

### Frontend
- HTML
- CSS

### Data Processing
- Pandas
- NumPy

### Visualization
- Matplotlib
